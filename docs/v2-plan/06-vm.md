# 06 `module/scripts/vm.sh`：crosvm 启停、熔断、磁盘

用法：`vm.sh start|stop|status|expand <MB>|reset-disk`。由 `xr` 调用，也可以单独运行。开头 `. "${MODDIR}/scripts/common.sh"`。

## 常量

```sh
CROSVM=/apex/com.android.virt/bin/crosvm
PID_F="${RUN}/crosvm.pid"
SOCK="${RUN}/crosvm.sock"
CON_LOG="${RUN}/console.log"
CTL_LOG="${RUN}/vm-ctl.log"
VMM_LOG="${XR_DATA}/log/vmm.log"
```

crosvm 只用这一个路径。不再查找其他位置，不再做 QEMU 回退，不再自动启用 hugepages 或 `--prepare-lend-mthp`。

## `vm_running`

```sh
vm_running() { p="$(cat "${PID_F}" 2>/dev/null)"; is_pid_running "$p" && grep -q crosvm "/proc/$p/cmdline" 2>/dev/null; }
```

## `vm_start`

前置条件，任一不满足就返回 1 并记日志：
- `vm_running` 为假；
- `TRIPPED` 文件不存在（存在时必须先执行 `xr ack-trip`）；
- `[ -x "${CROSVM}" ]`，并且 `${IMG}/Image` 和 `${IMG}/openwrt-rootfs.raw` 都存在；
- `ce_ready`（共享需要；不共享时只记警告，不阻止启动）。

```sh
vm_start() {
  load_config
  vm_running && { log_info vm "已在运行"; return 0; }
  [ -f "${TRIPPED}" ] && { log_err vm "熔断未确认"; return 1; }
  [ -x "${CROSVM}" ] && [ -f "${IMG}/Image" ] && [ -f "${IMG}/openwrt-rootfs.raw" ] || { log_err vm "缺少 crosvm 或镜像"; return 1; }
  mem="${VM_MEM_MB}"; [ "${mem}" -lt 384 ] && mem=512

  net_args=""
  if [ "${VM_NET}" = 1 ]; then
    sh "${MODDIR}/scripts/net.sh" up || { log_err vm "net up 失败"; return 1; }
    net_args="--net tap-name=xr0,mac=${XR_VM_MAC}"
  fi

  if [ "${VM_DISK_RW}" = 1 ]; then blk="${IMG}/openwrt-rootfs.raw,lock=false,root=true"; rootmode=rw
  else blk="${IMG}/openwrt-rootfs.raw,lock=false,root=true,ro=true"; rootmode=ro; fi

  . "${MODDIR}/scripts/share.sh"          # 见 09：设置 share_spec、share_mode、share_wrap
  share_prepare

  params="root=/dev/vda ${rootmode} rootwait console=ttyS0,115200 earlycon panic=5"
  params="${params} xr.ip=${XR_NET_PREFIX}.254/24 xr.gw=${XR_NET_PREFIX}.1 xr.dns=$(echo "${XR_DNS}" | tr ' ' ',')"
  params="${params} xr.vpnmode=${VPN_MODE} xr.share=${share_mode}"

  : > "${CON_LOG}"; : > "${CTL_LOG}"; rm -f "${SOCK}"
  fuse_arm
  ulimit -l unlimited
  [ "${VM_WAKELOCK}" = 1 ] && wakelock_on

  # shellcheck disable=SC2086
  ${share_wrap} nohup "${CROSVM}" --log-level=info run \
    --hypervisor gunyah --protected-vm-without-firmware --disable-sandbox \
    --no-balloon --swiotlb "${VM_SWIOTLB_MB}" --cpus "${VM_CPUS}" --mem "${mem}" \
    ${net_args} \
    --block "${blk}" \
    --serial "type=file,path=${CON_LOG},hardware=serial,num=1,console=true,earlycon=true" \
    --serial "type=file,path=${CTL_LOG},hardware=virtio-console,num=1" \
    --socket "${SOCK}" \
    ${share_spec:+--shared-dir} ${share_spec:+"${share_spec}"} \
    --params "${params}" \
    "${IMG}/Image" >> "${VMM_LOG}" 2>&1 &
  echo $! > "${PID_F}"
  sleep 2
  if ! vm_running; then
    log_err vm "crosvm 立即退出，详见 vmm.log"; rm -f "${FUSE}"; sync; wakelock_off
    [ "${VM_NET}" = 1 ] && sh "${MODDIR}/scripts/net.sh" down
    return 1
  fi
  ( fuse_watch ) >/dev/null 2>&1 &
  echo $! > "${RUN}/fuse_watch.pid"
  log_info vm "已启动 pid=$(cat "${PID_F}")"
}
```

`share_spec` 含空格（例如 uidmap），必须作为一个参数整体传给 `--shared-dir`。`share_wrap` 只在只读共享时非空，内容是 `unshare -m sh ${RUN}/share-ro.sh`，它在私有挂载命名空间里做完只读绑定后 `exec "$@"`，所以 crosvm 的 PID 不变。具体实现见 09。

## 熔断

```sh
fuse_arm() { printf '%s %s\n' "$(date +%s)" "$(config_hash)" > "${FUSE}"; sync; sleep 1; }

ready_seen() { grep -q '^XR_READY' "${CTL_LOG}" 2>/dev/null || grep -q 'XR_READY' "${CON_LOG}" 2>/dev/null; }

fuse_watch() {
  load_config; t=0
  while [ "$t" -lt "${READY_TIMEOUT_SEC}" ]; do
    vm_running || { rm -f "${FUSE}"; sync; log_err vm "就绪前 crosvm 已退出"; return; }
    ready_seen && break
    sleep 2; t=$((t+2))
  done
  if ! ready_seen; then log_err vm "${READY_TIMEOUT_SEC} 秒内未就绪，停止 VM"; vm_stop; return; fi
  echo ready > "${RUN}/state"; log_info vm "XR_READY"
  t=0
  while [ "$t" -lt "${STABLE_SEC}" ]; do
    vm_running || { rm -f "${FUSE}"; sync; log_err vm "稳定期内 crosvm 退出"; return; }
    sleep 5; t=$((t+5))
  done
  rm -f "${FUSE}"; config_hash > "${LAST_GOOD}"; sync
  echo stable > "${RUN}/state"; log_info vm "稳定，熔断已解除，last_good 已更新"
}
```

- 熔断文件在 crosvm 启动前写入并 `sync`。只有两种情况会删除它：稳定期结束，或者 crosvm 进程自行退出、正常停止。
- 整机复位时熔断文件留在磁盘上，`service.sh` 下次开机检测到后写 `tripped`，并把 `AUTOSTART` 设为 0（见 05）。

## `vm_stop`

```sh
vm_stop() {
  kill "$(cat "${RUN}/fuse_watch.pid" 2>/dev/null)" 2>/dev/null
  p="$(cat "${PID_F}" 2>/dev/null)"
  if vm_running; then
    "${CROSVM}" stop "${SOCK}" >/dev/null 2>&1
    i=0; while vm_running && [ $i -lt 10 ]; do sleep 1; i=$((i+1)); done
    vm_running && kill -TERM "$p"; sleep 5
    vm_running && kill -KILL "$p"
  fi
  rm -f "${PID_F}" "${SOCK}" "${RUN}/state" "${RUN}/fuse_watch.pid" "${FUSE}"; sync
  sh "${MODDIR}/scripts/net.sh" down
  wakelock_off
  log_info vm "已停止"
}
```

## `vm_status`（输出 JSON，供 `xr status-json` 使用）

字段：
- `running`（bool）
- `pid`
- `state`：`booting`、`ready`、`stable`，没有文件时为 `booting`
- `uptime_s`：`/proc/$pid` 的 `stat` 起始时间与当前时间之差
- `tripped`：`TRIPPED` 文件的内容，没有时为 null
- `last_good_match`（bool）
- `ready_channel`：`hvc`、`ttyS0` 或 null（判断 `XR_READY` 出现在哪个文件）

## 文件结尾的分派

`vm.sh` 被 `xr` 用 `.` 引入时只定义函数。直接运行时才走分派：

```sh
if [ "${0##*/}" = vm.sh ]; then
  case "$1" in start) vm_start;; stop) vm_stop;; status) vm_status;; *) exit 2;; esac
fi
```

## 磁盘

```sh
disk_expand() { # $1=新大小(MB)，必须大于当前大小，VM 必须已停止
  vm_running && { log_err vm "请先停止 VM"; return 1; }
  cur=$(( $(stat -c %s "${IMG}/openwrt-rootfs.raw") / 1048576 ))
  [ "$1" -gt "$cur" ] || return 1
  set_kv VM_DISK_SIZE_MB "$1" && truncate -s "$1M" "${IMG}/openwrt-rootfs.raw" && sync
  log_info vm "系统盘 ${cur}MB -> $1MB，下次启动时 VM 内执行 resize2fs"
}
disk_reset() {   # 重置系统盘：VM 内装过的包、改过的配置全部丢失
  vm_running && { log_err vm "请先停止 VM"; return 1; }
  load_config
  gzip -dc "${IMG}/openwrt-rootfs.raw.gz" > "${IMG}/openwrt-rootfs.raw.new" \
    && truncate -s "${VM_DISK_SIZE_MB}M" "${IMG}/openwrt-rootfs.raw.new" \
    && mv -f "${IMG}/openwrt-rootfs.raw.new" "${IMG}/openwrt-rootfs.raw" && sync
  rm -f "${LAST_GOOD}"
}
```

## 验收（在真机上）

- `vm.sh start`：`crosvm.pid` 存在，`console.log` 有内核输出；在 `READY_TIMEOUT_SEC` 之内，`vm-ctl.log` 或 `console.log` 出现 `XR_READY`。
- 再过 `STABLE_SEC` 秒：`vm_booting.fuse` 消失，`last_good` 内容等于 `config_hash`，`state` 为 `stable`。
- `vm.sh stop`：crosvm 进程消失，熔断文件、sock、pid 文件都被删除，wakelock 被释放（`cat /sys/power/wake_lock` 中没有 `x-route`）。
- `VM_NET=0` 时启动，命令行里没有 `--net`；`VM_DISK_RW=0` 时 guest 根分区为只读（`mount` 显示 `ro`）。
- `expand 2048` 后启动，guest 里 `df -h /` 显示约 2GB；`reset-disk` 后，VM 内之前安装的包消失。

# 第 7 步：WebUI 全面重做

## 目标

四个页面，底部顺序：**主页、互联、日志、设置**。自定义暗色下拉，不用系统 `select`。自定义暗色二次确认弹窗，不用系统默认框。文案精简优美，无解释性长文，无内部变量名，无取值前缀。

页面只调用 `xr`，不直接读写配置文件，不把启动进程绑在页面生命周期上（第 3 步已保证）。

## 依赖

- 依赖第 3–6 步的 CLI 与语义已经稳定：运行模式、OpenVPN 导入与状态、日志路径、固定配置项已从可设键中移除。
- 本步可新增 `xr log-export` 等仅为界面服务的命令，不得改网络语义。

## 要改的文件

- 重写 `module/webroot/index.html`、`style.css`、`app.js`
- `module/scripts/xr`：日志导出、状态字段若还需给界面（当前网络、运行时长、共享 rw 是否可用）
- 日志轮转：`module.log`、`vmm.log`、`console.log`、`vm-ctl.log` 均须轮转，不得写入 `/sdcard` 作为运行日志
- `tests/test-webui.sh`、必要时 `tests/test-xr.sh`

## 信息架构

去掉顶栏过长副标题。产品名显示 `XRouter`。连接徽章只保留极短状态（如「已连接」），不得被挤成两行。不要 `word-break: break-all` 拆中文或拆 `hvc` 这类短词；长日志可用 `break-word` 或等宽滚动。

底部固定四栏导航，当前页高亮。一次只渲染一个页。

### 主页

- 运行状态：启动完成后显示「运行中」；启动过程显示「启动中」；否则「已停止」。**不写「已稳定」「已就绪」**。
- 已运行时长、当前网络（上游简述：如 Wi-Fi / 蜂窝 / 无，不要暴露内部网卡名也可；若展示接口名，不要加前缀说明）。
- 按钮：启动、停止。停止需二次确认后再调用 `xr stop`。启动直接生效。
- 开机自动启动：开关，直接生效（现有熔断 / last_good 拒绝逻辑仍由 CLI 返回错误，页面用短句 toast 提示，不写长说明）。
- 管理界面：只保留 LuCI 链接（`http://<前缀>.254`）。不显示 SSH，不显示 ttyd，不做 SSH 端口映射。
- 保留熔断条：文案简短，例如「上次启动后整机复位，自启已关闭。」按钮「确认」。这不是第 8 节「主页异常提示」，而是已有安全机制。

### 互联

- 上传并启用 ovpn（文件选择 + 启用）。调用第 5 步的 `vpn-stage-*`。成功用短 toast。不重启虚拟机。
- 连接状态：如「未连接 / 连接中 / 已连接」，可附隧道地址，不展示密钥。
- 已接入的网段：只展示同步结果，不可编辑，无导入说明，无手工添加。

### 日志

这是手机侧管理虚拟机的记录，不是 OpenWrt 系统日志。

- 进入日志页后，再在页内切换四类，一次只看一份，顶部标明名称。默认「模块」。
- 四类对应：模块 → `module.log`；控制台 → `console.log`；控制通道 → `vm-ctl.log`；虚拟机管理器 → `vmm.log`。
- 一键导出：四个日志各成独立文件，打进一个 zip，保存到手机 Download。包名 `xrouter-logs-YYYYMMDD-HHMMSS.zip`，包内 `module.log`、`console.log`、`vm-ctl.log`、`vmm.log`（无内容则空文件也要占位，避免缺文件）。
- 也可单独导出当前类：`module-YYYYMMDD-HHMMSS.log` 等。
- 文件名只用英文与时间戳。时间戳用设备本地时间。
- 不做「清空日志」。
- 运行日志只写在 `${XR_DATA}/log` 与 `${RUN}`，超过约 512KB 轮转为 `.1`，不得无限堆积，不写到 `/sdcard`。

`xr log-export all|module|console|ctl|vmm` 在模块内打包或复制，目标目录优先 `/data/media/0/Download`，必要时再尝试 `/sdcard/Download`。导出是复制，不是把运行日志改到 Download。

### 设置

- **运行模式**：切换按钮，两项「全局」「旁路」，默认全局。切换弹出二次确认，确认后才 `xr set XR_MODE …`。
- **谁可以访问**：仅本机、热点设备、当前局域网。默认热点设备。自定义下拉。直接生效。蜂窝不能从外主动连入（已有逻辑，界面不解释）。
- **共享手机存储**：开关（默认关，直接生效）、只读或可读写（打开后默认只读）、路径。路径默认 `/data/media/0`，不用先手选。若填 `/sdcard` 或 `/storage/emulated/0`（含子路径），按同一处存储处理，实际挂载改写为 `/data/media/0`（或对应子路径）。不支持可读写时，直接禁用该选项，不叠两段提示。
- **CPU、内存**。
- **扩展系统盘、重置系统盘**：分开摆放，避免误触；都要二次确认。数字输入不要拉满整行导致错位。

### 二次确认（自定义暗色弹窗）

确认后再生效。文案保持一句：

| 操作 | 示例文案 |
|---|---|
| 切到全局 | 切换为全局？手机和热点将经 OpenWrt 出网。 |
| 切到旁路 | 切换为旁路？手机和热点将自行出网。 |
| 停止 | 停止虚拟机？ |
| 扩展系统盘 | 将系统盘扩展到 N MB？ |
| 重置系统盘 | 重置系统盘？虚拟机内的数据将全部丢失。 |

按钮：「取消」「确认」。弹窗样式与页面一致（暗色卡片、遮罩），不用 `window.confirm`、不用系统 Alert。

直接生效、无需确认：启动、开机自动启动、谁可以访问、共享开关与只读路径（rw 在支持时也可直接生效）。

### 自定义下拉

「谁可以访问」、共享权限、以及其它需要从列表选择的控件，一律自绘菜单：暗色背景、与卡片一致的边框和圆角，选项不折行混乱，不用原生 `select`。

### 从界面去掉的项

稳定期、swiotlb、就绪超时、系统盘可写、虚拟网卡、自启延迟、VPN 模式、手工网段、SSH、ttyd、内部变量名、取值前缀、成段 hint、清空日志、检查更新、Wi-Fi/热点开关。

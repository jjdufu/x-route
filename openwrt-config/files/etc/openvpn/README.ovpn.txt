# ==============================================================================
# x-route OpenVPN 异地组网双向互访配置指南
# ==============================================================================
#
# 1. 客户端配置 (本机 OpenWrt)：
#    - 将家里或机房导出的客户端配置文件保存为 /etc/openvpn/client.ovpn
#    - 或直接在 LuCI -> VPN -> OpenVPN 中上传 .ovpn 文件并勾选“已启用”。
#    - x-route 固件已预置 'vpn' 防火墙区域（绑定 tun+ 接口），默认允许
#      lan (192.168.100.0/24) <---> vpn (tun0) 双向转发与自动 MSS 钳制。
#
# 2. 服务端配置 (家里 / 机房 OpenVPN Server 实现反向访问手机热点设备)：
#    - 在 OpenVPN 服务端配置中加入：
#        client-config-dir /etc/openvpn/ccd
#        route 192.168.100.0 255.255.255.0
#    - 在服务端 /etc/openvpn/ccd/<手机客户端证书CN名> 文件中写入：
#        iroute 192.168.100.0 255.255.255.0
#    - 配置完成后，家里或机房内网任意机器可直接访问：
#        * 192.168.100.1 (手机 OpenWrt LuCI 后台 & OpenList:5244)
#        * 192.168.100.2 (OnePlus 13 宿主机自身服务，如 Alist Lite)
#        * 192.168.100.100~250 (连接在手机 Wi-Fi 热点下的任何笔记本/设备)
